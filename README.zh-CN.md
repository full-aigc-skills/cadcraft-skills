# CADCraft 技能库

本库提供 `cadcraft-use`、`cadcraft-cli`、`cadcraft-mcp` 三项独立技能。它们分别指导图纸任务分流、无窗口文件处理、MCP 精确绘图与验收。技能包不包含 CADCraft 可执行文件，使用前需核实 `cadcraft-cli` 已安装。

按需安装：`npx skills add full-aigc-skills/cadcraft-skills --skill cadcraft-use`。配套插件为 `full-aigc-plugins/cadcraft-plugin`，其内置技能快照通过哈希锁定。当前为 `0.1.0-dev.0` 开发版；结构验证不代表宿主安装或外部 CAD 格式兼容验收。
