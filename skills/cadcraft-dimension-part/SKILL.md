# 零件二维标注

## 任务起点

先读取素材，确认交付用途、目标尺寸或时长、修改范围与必要格式。能从任务和素材确定的细节直接采用合理默认值；只询问会改变结果的缺失条件。

需要可见编辑器时交给 **cadcraft-editor** 技能。独立安装：`npx skills add full-aigc-skills/cadcraft-skills --skill cadcraft-editor`。当前新增技能为本地候选，发布前使用本地配套插件，不把此安装命令当作已发布证明。

## 执行步骤

1. 确定长度单位、视图方向和公差来源。
2. 先画主体轮廓与对称轴，再绘制孔和槽。
3. 用基准标注关键尺寸，减少重复和闭合尺寸链。
4. 按目标纸张设置线型、线宽与比例。

## 工具落地

用 open/new_drawing 打开或新建，query_entities 核对几何；execute 执行命令，save 保存，render 预览。

先读取实际工具 schema，再填写参数；对象或文档 ID 使用返回值。查询到的命令必须在当前后端可用。保存前选择新输出路径，保留输入。需要的算法、格式或命令不存在时说明缺口，不能用相近名称冒充。

## 结果检查

- 查询孔径、中心距与轮廓边界。
- 检查尺寸是否过约束或遗漏。
- 工程与导出重开后单位、线型和标注文字保持一致。

对照用户目标检查实际内容，而不只检查进程退出码。局部编辑查看局部细节，版式任务查看整页，时间媒体查看起止与关键段。异常结果先检查当前工程，避免重复执行不可逆操作。

## 交付

返回可编辑工程、实际派生文件和简短说明：做了哪些修改、哪些步骤因当前能力未执行、需要用户判断的内容。只列真实存在且已经检查的文件。若用户随后返工，读取本次源工程并局部修改，保留已接受的内容。
