# 场景技能候选

新增技能位于 skills/，独立技能源维护，插件本地候选按 scenario-candidates.json 校验。既有发布快照不变。当前完成内容与实际场景视觉验收分开；尚未逐场景完成用户素材验收。

- `cadcraft-floor-plan`：房间平面图（按尺寸绘制房间与门窗）
- `cadcraft-dimension-part`：零件二维标注（机械零件轮廓、孔位和尺寸）
- `cadcraft-trace-reference`：参考图描绘（依据图片或草图建立矢量图纸）
- `cadcraft-layer-cleanup`：图层整理（复杂图纸的图层、线型和重复线清理）
- `cadcraft-sheet-export`：图纸出图（图框、纸张、比例与打印输出）
- `cadcraft-compare-revisions`：图纸版本比对（两版图纸的几何和标注差异）
